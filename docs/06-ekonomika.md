# 6. Экономика: API, аренда или своё железо

Все цены на 25 сентября 2026, в долларах США. Источники — в [istochniki.md](istochniki.md).

---

## 6.1. Главная особенность агентной нагрузки

Агент на каждом ходу отправляет модели **всю историю**: 100–250K токенов контекста. При этом
генерирует обычно 0.5–2K токенов. На **1 сгенерированный токен приходится ~50–150 прочитанных**.

- **В API** вы платите за чтение каждый раз. Даже со скидкой на кэш это основная часть счёта.
- **На своём сервере** повторное чтение почти бесплатно: кэш префиксов (глава 5) пересчитывает только
  новые токены. Вы платите за время GPU, а не за токены.

Поэтому для роя с длинными контекстами сравнивать надо **стоимость 1 млн сгенерированных токенов
с учётом прочитанного контекста**, а не прайс «за 1М входных».

## 6.3. Сколько стоит аренда

Та же нагрузка на своём vLLM: платите только за часы GPU. Оценка при **полной загрузке**
(10 агентов, контексты заполнены на ~60%), расчёт `scripts/vram_calc.py --compare`:

| Конфигурация | $/час | Суммарно ток/с | **$ за 1 млн сгенерированных токенов** |
|---|---|---|---|
| 1× H200 (RunPod) | 4.59 | ~630 | **~$2.0** |
| 1× B200 (RunPod) | 6.79 | ~980 | **~$1.9** |
| 2× RTX PRO 6000 (RunPod) | 4.18 | ~460 | ~$2.5 |
| 2× RTX PRO 6000 (Vast.ai, медиана) | 2.78 | ~460 | **~$1.7** |

Префилл новых токенов на каждом ходу добавляет к времени GPU ~5% (секунда на ход против
~25 секунд генерации) и в цене уже учтён с запасом точности оценки.

**Вывод:** при полной загрузке аренда примерно **в 4–6 раз дешевле API с кэшем** и в 10–20 раз
дешевле API без кэша.

### Точка безубыточности аренды против API

H200 при полной загрузке выдаёт ~2.27 млн токенов в час. Та же работа через API стоит
~$17.7/час (DeepInfra) или ~$27.7/час (OpenRouter), а аренда — $4.59/час. Значит:

> **Аренда выгоднее API, если рой загружает GPU больше чем на ~20–25% оплаченного времени.**

С посекундной оплатой (RunPod, Vast.ai) это легко: включили машину → отработал рой → выключили.

| | 1× RTX PRO 6000 (ПК) | 2× RTX PRO 6000 (рабочая станция) |
|---|---|---|
| Покупка (сентябрь 2026) | ~$22–24K | ~$42–52K |
| Ёмкость | 7 × 256K или 10 × ~180K | 15 × 256K |
| Потребление под нагрузкой | ~0.8 кВт | до ~1.5 кВт (Workstation) / ~1.0 кВт (Max-Q) |

| Эквивалентная аренда | $2.09/ч (RunPod), $1.39/ч (Vast) | $4.18/ч (RunPod), $2.78/ч (Vast) |

**Окупаемость покупки против аренды тех же карт** (цена покупки ÷ (аренда − электричество)):

| Режим работы | 1× RTX PRO 6000 ($23K) | 2× RTX PRO 6000 ($47K) |
|---|---|---|
| 24/7, против RunPod | ~16 мес. | ~16 мес. |
| 24/7, против Vast.ai | ~24 мес. | ~24 мес. |
| 12 ч/день, против RunPod | ~2.6 года | ~2.6 года |
| 8 ч × 22 дня, против RunPod | ~5.5 лет | ~5.5 лет |

Что ещё учесть:
- **Цены на GPU в 2026 завышены дефицитом памяти** (RTX PRO 6000 подорожала почти вдвое за год).
  Когда дефицит пройдёт, купленное сейчас железо может заметно подешеветь на вторичке.
- **Ваше время:** своё железо — это сборка, охлаждение, обновления драйверов, простои при поломках.
- **Плюсы своего:** данные физически у вас; нет очереди за дефицитными GPU у провайдеров;
  карта сохраняет часть стоимости при перепродаже.

## 6.5. Итог

| Ваша ситуация | Что выбрать |
|---|---|
| Хотите быстро попробовать и оценить качество | **API** (OpenRouter, DeepInfra) — десятки долларов |
| Рой работает эпизодически или несколько часов в день | **Аренда по часам**: 1× H200 или 2× RTX PRO 6000; B200, если важна максимальная скорость |
| Рой работает почти круглосуточно, месяцами | **Аренда с обязательством** (скидка 20–35%) или **покупка 2× RTX PRO 6000** (окупится за ~1.5–2 года) |
| Данные нельзя отдавать третьим лицам | **Покупка** (или выделенный сервер у надёжного провайдера по договору) |

**Практический путь:** 1) проверить качество модели через API → 2) арендовать H200 на пару часов
и прогнать `bench_swarm.py` и свой рой → 3) по реальной загрузке и замерам решить, продолжать
аренду или покупать.

## 6.6. Формулы, чтобы пересчитать под свои цифры

```
Стоимость токенов на аренде ($ за 1М сгенерированных) = цена_часа / (суммарные_ток/с × 3600) × 1 000 000

Стоимость хода агента в API = (контекст − новые) × цена_кэша + новые × цена_входа + ответ × цена_выхода

Окупаемость покупки (часов) = цена_железа / (цена_аренды_часа − электричество_в_час)
```

Суммарные ток/с берите из `bench_swarm.py` на вашей нагрузке. Оценка калькулятора — только ориентир.
